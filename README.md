## 02 — Architectural System & Features

### Global HUD & Coordinate Layer
- Smoothly interpolated mouse pointer coordinates (`x 000.000 / y 000.000`)
- Minimalist branding and system metadata (`SYS 01 / 2026`)
- Accessible desktop navigation and animated full-screen mobile menu overlay

### Dynamic Background Canvas (`LiveCanvas`)
- Pure HTML5 Canvas rendering without heavy external WebGL dependencies
- Throttled `requestAnimationFrame` loop with zero React re-renders during motion
- Mode-reactive visual behaviors:
  - **Hero/Default:** Ambient coordinate particles with connection lines
  - **QR Menu:** Architectural geometric grid system
  - **Mobile:** Flowing interconnected node graph
  - **AI & CV:** Neural network layered columns
  - **About/Contact:** Calm organic ivory drift
- Native support for `prefers-reduced-motion: reduce`

### Custom Cursor (`CustomCursor`)
- Spring-interpolated cursor with dynamic contextual states:
  - `Default` (small point)
  - `Hover interactive` (ring)
  - `VIEW` (case studies & cards)
  - `DRAG` (interactive graphs)
  - `EXPLORE` (capability nodes)
- Automatically disabled on touch-screen devices

### Interactive Working Demonstrations
1. **Digital QR Menu Systems (`/work/qr-menu-systems`)**:
   - Live Brand Editor (venue name, subtitle, accent color tokens, surface theme, font choices)
   - Dynamic Menu Editor (categories, live price modification, dish addition, item deletion, offer toggling)
   - Offers & Promos Banner Manager
   - Generative Table QR Code Artifact
   - Realistic Customer Mobile Preview with instant bi-directional updates
2. **Mobile Application Development (`/work/mobile-applications`)**:
   - Native Phone Frame (`9:41`) with curriculum learning flow
   - Multi-language switcher supporting English, Français, and Arabic (`العربية`)
   - **True RTL Layout Transition**: switches text alignment, mirrored icons, progress bar directions, and Arabic typography
   - Reusable Component Inspector toggle (`<UserGreeting />`, `<ActiveLessonTracker />`, `<CurriculumModulesList />`, `<AiAssistantPrompt />`)
3. **Machine Learning & Computer Vision (`/work/machine-learning-computer-vision`)**:
   - 5-stage interactive pipeline: `01 DATA`, `02 PREPROCESS`, `03 TRAIN`, `04 EVALUATE`, `05 PREDICT`
   - Real PyTorch code fragments (`ImageFolder`, `transforms`, autograd forward/backward loops)
   - Architectural visual representations (stratified splits, tensor shapes, convolutional layers, confusion heatmap)
   - Explicit ethical disclosure: *Illustrative visualization — not model results.*
